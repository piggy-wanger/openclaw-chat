# G1.1-G1.5: 群组 UI

## 目标

为群组聊天打造完整的 UI 体验，包括专用的群消息组件、多 Agent 并发流式展示、群组 ChatHeader 和侧边栏接入。

## 背景

项目已有：
- `hooks/useGroupChat.tsx` — GroupChatProvider，提供 messages（GroupMessage[]）、members（GroupMember[]）、streamingMap（Map<agentId, {isStreaming, content, runId}>）、sendMessage、abortStream
- `app/page.tsx` — GroupChatArea 组件，目前用 formattedMessages 将 GroupMessage 转为 Message 格式，在 senderName 前加前缀。MessageList 只支持单 streamContent，无法展示多个 Agent 同时 streaming
- `components/chat/MessageItem.tsx` — 单 Agent 消息渲染组件，带 Markdown、ToolCall、时间戳
- `components/chat/MessageList.tsx` — 消息列表，接受 Message[] + 单个 streamContent + isStreaming
- `components/chat/ChatHeader.tsx` — 聊天头部
- `components/chat/InputArea.tsx` — 输入框，已支持 isGroup + groupAgents props
- `components/sidebar/SessionList.tsx` — 会话列表，已分"直接聊天"和"群聊"两组
- `lib/types.ts` — GroupMessage { id, groupId, senderType, senderId, senderName, senderEmoji, role, content, runId, toolCalls, createdAt }

## 要实现的文件

### 1. `components/chat/GroupMessageItem.tsx`（新建）

群组专用消息渲染组件，参考 MessageItem.tsx 的模式但适配群组场景。

**要求：**
- 用户消息：右对齐，蓝色气泡，不带 sender 信息（跟直接聊天一致）
- Agent 消息：左对齐，带 sender 头像（emoji 或默认图标）+ senderName + 内容
- senderName 用不同颜色区分不同 Agent（根据 agentId hash 生成稳定的颜色）
- 支持 Markdown 渲染（复用 MarkdownRenderer）
- 支持 ToolCall 展示（复用 ToolCallList）
- 时间戳显示（HH:mm 格式）
- 用 React.memo 优化，避免不必要的 rerender
- 导出 GroupMessageItem

### 2. `components/chat/GroupMessageList.tsx`（新建）

群组专用消息列表组件，替代 GroupChatArea 中当前复用的 MessageList。

**要求：**
- 接受 props：
  ```typescript
  {
    messages: GroupMessage[];
    streamingMap: Map<string, StreamingState>;
    members: GroupMember[];
    loading?: boolean;
  }
  ```
- 使用 GroupMessageItem 渲染历史消息
- 在消息列表底部展示所有正在 streaming 的 Agent 的流式内容（每个 Agent 一个独立气泡，带 emoji + name + 流式文本 + 打字光标）
- 没有消息时显示空状态
- loading 时显示骨架屏
- 自动滚动到底部（参考 MessageList.tsx 的 shouldAutoScroll 逻辑）
- 用 React.memo 包裹

### 3. `components/chat/ChatHeader.tsx` 修改

在现有 ChatHeader 基础上增加群组模式支持。

**要求：**
- 新增 prop `isGroup?: boolean`、`groupName?: string`、`groupMembers?: GroupMember[]`
- 群组模式下：
  - 标题显示群名（而不是 Agent 名）
  - 副标题显示成员数（如 "3 个智能体"）
  - 标题旁显示成员 emoji 头像列表（最多显示 5 个，超出显示 +N）
- 直接聊天模式保持不变

### 4. `app/page.tsx` 中 GroupChatArea 修改

**要求：**
- 将 MessageList 替换为 GroupMessageList
- 将 ChatHeader 改为群组模式（传入 isGroup, groupName, groupMembers）
- 移除 formattedMessages（不再需要把 GroupMessage 转为 Message）
- 直接传 messages（GroupMessage[]）和 streamingMap 给 GroupMessageList
- 移除旧的 streamContent 单一变量

### 5. `components/sidebar/SessionList.tsx` / `SessionItem.tsx` 修改

**要求：**
- 群组 session item 显示成员 emoji 列表（小头像），而不是单个 Agent 头像
- 显示成员数 badge（如 "3"）
- 如果 SessionList 已经有群组/直接聊天分组，确认群组列表正确渲染

## 验收标准

1. npm run build 通过，无 TypeScript 错误
2. GroupMessageItem 正确渲染用户消息和 Agent 消息，不同 Agent 有不同颜色
3. GroupMessageList 能同时展示多个 Agent 的流式内容
4. ChatHeader 群组模式显示群名 + 成员头像
5. 侧边栏群组 item 显示成员信息
6. 直接聊天功能不受影响（回归）
7. 不修改 hooks/useGroupChat.tsx（数据层已完成，UI 层不应改数据逻辑）
8. 不修改 API routes

## 约束

- 不修改 hooks/useGroupChat.tsx
- 不修改 app/api/ 下的任何文件
- 不修改 db/ 下的任何文件
- 保持与现有设计风格一致（参考 MessageItem.tsx 的样式）
- 使用项目已有的 UI 组件（shadcn/ui 的 Avatar、Badge 等）
