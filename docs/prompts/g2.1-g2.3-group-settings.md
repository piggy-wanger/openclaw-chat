# G2.1-G2.3: 群组管理

## 目标

实现群组管理功能：群组设置对话框（编辑群名、管理成员）、CreateGroupDialog 优化、成员在线状态显示。

## 背景

项目已有：
- `app/api/groups/[id]/route.ts` — PATCH 更新群组（名称、头像）、DELETE 删除群组
- `app/api/groups/[id]/members/route.ts` — GET 成员列表、POST 添加成员、DELETE 移除成员、PATCH 更新成员
- `components/dialogs/CreateGroupDialog.tsx` — 已接入真实 API（通过 useSession 的 createGroupSession）
- `hooks/useSession.tsx` — createGroupSession 已调 /api/groups 创建群组和成员
- `hooks/useGroupChat.tsx` — 提供 group, members, messages, streamingMap 等
- `components/chat/ChatHeader.tsx` — 群组模式显示群名 + 成员头像
- `lib/types.ts` — Group, GroupMember, GroupMessage 类型

## 要实现的文件

### 1. `components/dialogs/GroupSettingsDialog.tsx`（新建）

群组设置对话框，支持编辑群名和管理成员。

**要求：**
- 使用 shadcn/ui 的 Dialog 组件（参考 CreateGroupDialog.tsx 的模式）
- Props：
  ```typescript
  {
    open: boolean;
    onOpenChange: (open: boolean) => void;
    groupId: string | null;
    onGroupUpdated?: () => void;
  }
  ```
- 打开时 fetch 群组详情和成员列表
- **编辑群名**：Input 组件修改群名，调 PATCH /api/groups/[id]
- **管理成员**：
  - 显示当前成员列表（emoji + name + role）
  - 支持添加新成员（从 Gateway config.agents 获取可选列表，排除已加入的）
  - 支持移除成员（DELETE /api/groups/[id]/members/[agentId]）
  - 添加成员调 POST /api/groups/[id]/members
- **删除群组**：底部红色按钮，确认后调 DELETE /api/groups/[id]，然后通知父组件刷新
- 操作成功后调 onGroupUpdated 回调
- Loading 状态处理

### 2. `components/chat/ChatHeader.tsx` 修改

在群组模式 ChatHeader 中添加设置入口。

**要求：**
- 群组模式下，标题旁或右侧添加"设置"图标按钮（Settings 图标）
- 点击打开 GroupSettingsDialog
- 传入当前 groupId（从 session.groupId 获取）和 onGroupUpdated 回调

### 3. `hooks/useGroupChat.tsx` 修改 — 成员在线状态

**要求：**
- 新增 `membersOnline: Map<string, boolean>` 状态（agentId → 是否在线）
- GroupChatContextType 新增 `membersOnline` 字段
- 利用 Gateway 的 `sessions.list` 或 agent 事件来判断成员是否在线
- 简单实现：监听 Gateway 的 agent 事件，如果收到某个 agentId 的事件就标记为在线；或者在 fetchGroupData 时通过 sessions.list 检查每个 member 的 sessionKey 是否有活跃 session
- 更简单的方案：假设成员始终在线（群组是本地创建的 Agent，不存在离线概念），但预留 membersOnline 字段和 UI 插槽
- **推荐采用简单方案**：预留字段，显示绿色圆点表示在线，不做真正的在线检测（Gateway 目前没有 agent 在线状态 API）

### 4. `components/chat/GroupMessageItem.tsx` 修改

**要求：**
- Agent 消息头像旁加一个小绿色圆点表示"在线"
- 圆点用 membersOnline 数据（当前全部显示绿色）

## 验收标准

1. npm run build 通过
2. GroupSettingsDialog 可以编辑群名、添加/移除成员、删除群组
3. ChatHeader 群组模式有设置按钮，点击打开对话框
4. GroupMessageItem 显示在线状态圆点
5. 不修改 API routes（已实现）
6. 直接聊天功能不受影响

## 约束

- 不修改 app/api/ 下的任何文件
- 不修改 db/ 下的任何文件
- 参考 CreateGroupDialog.tsx 的代码风格和 Dialog 用法
- 参考 ChatHeader.tsx 现有的 props 模式
- 使用项目已有的 UI 组件（Dialog, Input, Button, Badge, Avatar 等）
